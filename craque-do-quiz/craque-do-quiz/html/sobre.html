O Craque do Quiz é um projeto acadêmico que transforma a paixão pelo futebol em um desafio de perguntas, aprendizado e competição saudável.

🎯

Objetivo

Testar conhecimentos sobre futebol de forma simples e divertida, usando recursos fundamentais do desenvolvimento web.

💻

Tecnologias

HTML para estruturar as páginas, CSS para o visual responsivo e JavaScript para controlar o quiz e salvar os resultados.

Como funciona

As regras da partida

  1. 01
    Monte sua partida

    Informe seu nome, escolha uma categoria e selecione a dificuldade.

  2. 02
    Responda no tempo

    Você terá 15 segundos por pergunta. Respostas rápidas valem pontos extras.

  3. 03
    Use sua ajuda

    A ferramenta 50/50 remove duas alternativas incorretas uma vez por partida.

  4. 04
    Entre para o ranking

    Ao terminar, sua pontuação é salva no ranking deste navegador.
