CRAQUE DO QUIZ 

ORGANIZACAO
html/ - contem as cinco paginas do site.
css/style.css - contem a aparencia do site.
js/ JavaScript necessario para o jogo funcionar.

ARQUIVOS JAVASCRIPT
inicio.js - le o formulario e inicia a partida.
perguntas.js - guarda as perguntas e alternativas do quiz.
quiz.js - controla perguntas, respostas, tempo e pontuacao.
resultado.js - mostra o resultado da partida.
ranking.js - mostra e organiza as pontuacoes salvas.
sobre.js - controla o formulario de sugestoes.
common.js - contem funcoes pequenas usadas em mais de uma pagina.

HTML organiza o conteudo das paginas.
CSS define cores, espacamentos, tamanhos e posicionamento.
JavaScript faz as interacoes: iniciar o jogo, conferir respostas, contar pontos e salvar o ranking.

O ranking usa localStorage e fica salvo no navegador do proprio dispositivo. Nao e um ranking online compartilhado.
