# ⚽ Craque do Quiz

O **Craque do Quiz** é um jogo de perguntas e respostas sobre futebol, desenvolvido como projeto acadêmico utilizando HTML, CSS e JavaScript.

## 🎮 Funcionalidades

- Perguntas sobre Copa do Mundo, clubes, jogadores e regras do futebol.
- Três níveis de dificuldade.
- Cronômetro e sistema de pontuação.
- Ajuda 50/50 e sorteio de alternativas.
- Ranking de pontuações salvo no navegador.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📁 Organização

- `html/` – páginas do projeto.
- `css/` – estilos visuais.
- `js/` – funcionalidades e perguntas do quiz.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo `html/index.html` utilizando o Live Server.
